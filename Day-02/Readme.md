# Day 02 - Password Strength Checker

## Project Overview

Password Strength Checker is a Python-based command-line application that analyzes the strength of a user-entered password and provides security recommendations.

The application evaluates passwords based on multiple factors such as length, uppercase letters, lowercase letters, numbers, and special characters. It then categorizes the password as Weak, Medium, or Strong and suggests improvements when needed.

## Features

* Check password strength instantly
* Categorize passwords as:

  * Weak
  * Medium
  * Strong
* Analyze:

  * Password length
  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* Security improvement suggestions
* Copy password to clipboard using Pyperclip

## Technologies Used

* Python
* String Module
* Pyperclip

## Installation

Clone the repository and install the required package:

```bash
pip install pyperclip
```

## Run the Project

```bash
python Password_Generator.py
```
