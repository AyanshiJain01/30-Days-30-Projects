# 💻 Coding Activity Analyzer

Day 06 of my **30 Days 30 Projects Challenge**

A Python-based Data Analytics project that analyzes coding activity data and generates meaningful insights such as coding streaks, productivity trends, topic strengths, platform performance, rating growth, difficulty progression, and burnout detection.

---

## 🚀 Project Overview

This project analyzes 6 months of coding activity data collected from various coding platforms such as LeetCode, GeeksforGeeks, and Codeforces.

Using Python, Pandas, Matplotlib, Streamlit, and Plotly, the project extracts valuable insights from the dataset and visualizes them through interactive charts and dashboards.

---

## 📊 Features

### Basic Analysis

* Total Problems Solved
* Total Coding Hours
* Average Problems Solved Per Day
* Total Contests Participated

### Streak Analysis

* Longest Coding Streak
* Consistency Tracking

### Productivity Analysis

* Best Coding Day
* Worst Coding Day
* Most Productive Weekday

### Topic Strength Analysis

* Strongest Topic
* Weakest Topic
* Topic-wise Performance

### Platform Performance

* LeetCode vs GFG vs Codeforces Analysis
* Platform Usage Percentage

### Difficulty Analysis

* Easy, Medium, Hard Problem Distribution
* Difficulty Progression Over Time

### Contest Analysis

* Rating Growth
* Average Rating Gain
* Best Contest Performance
* Worst Contest Performance

### Monthly Growth Analysis

* Monthly Problem Solving Trend
* Growth Percentage Tracking

### Burnout Detection

* Detects days with high effort but low output
* Identifies potential productivity drops

### Interactive Dashboard

* Platform Filter
* Topic Filter
* Date Range Filter
* Dynamic Charts
* Smart Insights

## ▶️ Run Locally

### Install Dependencies

```bash
pip install pandas matplotlib streamlit plotly
```

### Run Analytics Script

```bash
python main.py
```

### Launch Dashboard

```bash
streamlit run app.py
```
